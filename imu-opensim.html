IMU-to-OpenSim Motion Pipeline

Streaming IMU sensor data into OpenSim to analyze human motion — a personal project built to sharpen my wearable sensing and biomechanical modeling skills.

Status
In progress
Timeline
Ongoing
Stack
IMU Sensors · Python · OpenSim

The Idea

Motion capture in a lab is precise but expensive and confined to a fixed volume. Wearable IMUs — inertial measurement units — can measure motion anywhere. The tradeoff is turning raw accelerometer and gyroscope data into something a biomechanics tool can actually use.

This project is my attempt to close that gap: a pipeline that takes IMU sensor output and feeds it into OpenSim, an open-source platform for modeling and simulating musculoskeletal movement, so wearable data can drive the kind of motion analysis normally reserved for marker-based lab setups.
